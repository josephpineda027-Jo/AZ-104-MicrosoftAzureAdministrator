Lab 01: Managing Microsoft Entra ID & RBAC:

What I Built & Learned
- Configured cloud identities by creating and managing user accounts and guest users within a Microsoft Entra ID tenant.
- Implemented organizational structure by setting up Security groups and M365 groups with assigned and dynamic memberships.
- Applied the **Principle of Least Privilege** by scoping down permissions using Azure Role-Based Access Control (RBAC) rather than assigning broad administrative roles.

Key Takeaways & Troubleshooting
- Tenant Boundaries: An Entra ID tenant serves as a secure directory service boundary for an organization.
- Dynamic Groups: Useful for automating user lifecycle management based on department or job title attributes.
